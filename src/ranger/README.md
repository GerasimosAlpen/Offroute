# ranger page

Ranger page is only **FOR DESKTOP** and can't be shown to mobile.

## roles

there we'll be two roles with three page that ranger have

- radar: that will be using the desktop version ONLY and watching the condition and all of the reports, sending personel to the location, and taking a decision, communicate with the personel, and maintain the location that they have (node), mark everything if there's an accident or something happen like flood, or tsunami, so we can send all the help, also send FLARE if it's a really big accident like earthquake, this will also responsible to give the personel evacuation route.
- personel: will be given phone version, that will patrol and move if there's something happening, and should react fast to the location, taking the communication with the user from radar, and send status to the radar, if they need something like some big tools, or evacuation route (if there are none, then they're need to take control).

## requiremenets

- need a realtime data stream
- taking control of the hardware status
- offline mode, in case if the radar location got flooded or can't be used, changing into bluetooth to send all of the data across
- finding the best route
- need to be really lightweight and easy to use
